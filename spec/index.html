Specification Index

このディレクトリの文書は、役割ごとのサブディレクトリに分け、次の優先順位で扱う。

  • docs/: 実行中または完了条件が残る計画と実装設計
  • docs/.archived/: 完了、置換、または後続計画へ移管済みの歴史的計画
  • concepts/: 長期的に参照するプロダクト境界と方向性
  • decisions/: 意思決定、運用契約、runbook、policy
  • templates/: 証跡または意思決定の再利用可能な雛形

Scan Profile Execution Architecture Migration Planは、scan profileの実行経路、readiness、 依存資格、進捗、cleanup、qualificationに関する正本である。既存のcatalog統合計画とstability promotion計画が同じ領域で競合する場合は、この計画を優先する。

Phase 56が、security capability、professional claim、product completion、 release closeoutに関する唯一の親計画である。他のactive planは、UI刷新またはcross-repository integrationなど、Phase 56と異なる完了境界を持つ。

Backend Scanner計画は、Phase 56 Slice 56.11のscan backend / scanner verificationについて、実行順、todolist固定target、個別scanner test、acceptance gateを定義する。

Scanner Hardening Archive Closeout計画は、Backend Scanner計画の機能scopeを増やさず、 変更範囲の固定、Definition of Doneの証跡化、strict gateの終了記録とarchive handoffを扱う。

このsubordinate planはPhase 56のclaim、UI、release scopeを変更しない。
