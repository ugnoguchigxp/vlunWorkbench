  • docs/: 実行中または完了条件が残る計画と実装設計

  • templates/: 証跡または意思決定の再利用可能な雛形

Backend Scanner計画は、Phase 56 Slice 56.11のscan backend / scanner verificationについて、実行順、todolist固定target、個別scanner test、acceptance gateを定義する。

Scanner Hardening Archive Closeout計画は、Backend Scanner計画の機能scopeを増やさず、 変更範囲の固定、Definition of Doneの証跡化、strict gateの終了記録とarchive handoffを扱う。

Improvement Request Warning Rollup計画は、既存issue groupingを監査の正本として維持し、 改修依頼生成時だけ同種警告を親、検出場所を子へ投影してprompt文字数上限内へ収める。

このsubordinate planはPhase 56のclaim、UI、release scopeを変更しない。
