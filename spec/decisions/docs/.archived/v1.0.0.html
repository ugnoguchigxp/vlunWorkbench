vulnWorkbench v1.0.0

Status: technical release; professional capability claim not_met

This technical release candidate provides the local AppSec evidence workflow, strict authorization/network/secret boundaries, serialized SQLite writes, bounded scanner execution, deterministic reporting, and optional evidence-constrained LLM diagnosis.

The professional measured-capability claim remains not_met. The pinned OWASP Benchmark run has recall 0.7088, precision 0.6946, false-positive rate 0.3121, and score 0.3967. Juice Shop has 20 eligible scenarios in 9 categories but no accepted runtime observations. These limitations do not become a pass merely because the technical release gates pass.

The release commit is accepted only after clean-checkout strict verification, verified backup/restore, all three maintained container builds and security scans, offline toolbox verification, real-scanner DAST evidence, and the capability report. Any later source change requires a new patch release and a new immutable tag.
